The Windowsill Prophecy: one kind, funny fortune for the houseplant on the windowsill — the sun crowns its newest leaf this week, and its keeper is so proud they brag about it to the neighbours.

> By Sunday, the windowsill sun will crown your newest leaf, and your keeper will brag about you to the neighbours.

## Run it

```sh
node main.ts
```

The program writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. It refuses to run if the fortune is not 1–120 characters, so the gate can never see an invalid entry.
